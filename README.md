## `$ ls -la ./projetos`

<table>
<tr>
<td width="50%" valign="top">

### 🛰️ PULSO-Sentinel

**Re-identificação de dispositivos Wi-Fi via clock skew**

Projeto de Iniciação Científica (FAI → CIC/2026) que identifica dispositivos Wi-Fi mesmo com randomização de MAC ativa, usando o desvio do relógio TSF extraído de Probe Requests.

```
captura    → tshark
processamento → Python + RANSAC/Kalman
classificação → Siamese Network (contrastive loss)
```

`#RF-Fingerprinting` `#MachineLearning` `#Wireshark`

</td>
<td width="50%" valign="top">

### 🗂️ BibliotecaMidia / SchoolNet

**Ferramenta desktop de mídia e suporte técnico**

App Python/Tkinter criado para resolver um gargalo real no ambiente escolar: downloads, transferência de arquivos e diagnóstico de rede sob demanda.

```
gui/       → interface Tkinter nativa
download/  → yt-dlp + ffmpeg
security/  → SHA-256 + bloqueio de extensões
utils/     → suíte de diagnóstico com 8 categorias
```

`#Python` `#Automação` `#SuporteTI`
